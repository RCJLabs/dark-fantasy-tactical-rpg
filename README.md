# Dark Fantasy Tactical RPG

Solo-developed mobile dark fantasy tactical RPG.

## Current Status
Starter kit for core systems:
- Grid generation
- Units
- Turn management
- Skill system foundation (with synergy hooks)

## Setup
1. Clone the repo
2. Open in Unity (2022.3+ recommended, URP)
3. Create a Tile prefab (Cube scaled to 1, 0.1, 1 with Tile component)
4. Assign it to GridManager
5. Add Units to the scene
6. Play
